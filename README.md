# Евробюджет

Личный учёт доходов и расходов в евро: лимиты, подсказки как уложиться, список покупок на неделю, цели, подушка безопасности и калькулятор сложного процента.

Все записи хранятся только в браузере (localStorage) и никуда не отправляются. Для переноса на другое устройство используйте «Резервная копия → Скачать копию / Загрузить из файла».

Сайт — один файл `index.html`, публикуется через GitHub Pages.
